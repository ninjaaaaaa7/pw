# GenAI Legal Assistant

Dual-pane web app: paste contract text, get a structured breakdown (summary,
risk flags, obligations, questions for an attorney) generated by Claude Opus 5.

```
backend/   FastAPI + anthropic SDK        (port 8000)
frontend/  Next.js App Router + Tailwind  (port 3000)
```

## Backend

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate   |   macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # then paste your ANTHROPIC_API_KEY
uvicorn main:app --reload --port 8000
```

`POST /api/analyze-document` with body `{"document_text": "..."}` returns
`{executive_summary, risk_flags[], user_obligations[], lawyer_questions[]}`.

## Frontend

```bash
cd frontend
npm install
cp .env.local.example .env.local   # optional; defaults to http://localhost:8000
npm run dev
```

Open http://localhost:3000.

> This tool does not provide legal advice.
